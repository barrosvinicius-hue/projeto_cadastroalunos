PROJETO INTEGRADO - CADASTRO DE ALUNOS

1) Instale Python 3.
2) Abra o terminal nesta pasta.
3) Execute: pip install -r backend/requirements.txt
4) Execute: cd backend
5) Execute: python app.py
6) Abra no navegador: http://127.0.0.1:5000

As pastas estão separadas: backend, frontend, css, js, database e documentacao.
